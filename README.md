# Enterprise IT Service Management Portfolio

## Overview

This repository demonstrates practical experience with Enterprise IT Service Management (ITSM) concepts using Jira Service Management and ServiceNow. The projects simulate real-world service desk operations, incident handling, change management, CMDB administration, service requests, reporting, and workflow automation commonly performed by IT Support Engineers, Service Desk Analysts, and Junior System Administrators.

The portfolio follows ITIL-aligned service management practices and focuses on hands-on configuration rather than theoretical concepts.

# Projects

| Project | Description |
|---------|-------------|
| **01 – Jira Service Management Help Desk** | Configured a Jira Service Management help desk, created queues, request types, SLAs, customer portal, and ticket workflows. |
| **02 – Incident, Request and Problem Management** | Managed incidents, service requests, and problem records while understanding the relationship between ITIL operational processes. |
| **03 – SLA, Priority and Escalation Management** | Configured ticket priorities, SLA targets, escalation workflows, and response objectives for enterprise support operations. |
| **04 – ServiceNow ITSM Fundamentals** | Explored the ServiceNow interface, created and managed incidents, assigned tickets, updated states, and worked with core ITSM modules. |
| **05 – ServiceNow Change Management** | Created and processed change requests through the complete change lifecycle, including assessment, authorization, scheduling, implementation, review, and closure. |
| **06 – ServiceNow CMDB and Asset Management** | Explored Configuration Items (CIs), hardware assets, CMDB records, and asset relationships while understanding enterprise configuration management concepts. |
| **07 – ServiceNow Service Operations** | Worked with the Service Catalog, submitted service requests, tracked requested items (REQ/RITM), created knowledge articles, and explored self-service support. |
| **08 – ServiceNow Reporting and Automation** | Created reports, reviewed dashboards, explored Flow Designer workflows, and examined automated email notifications for operational visibility and workflow automation. |
